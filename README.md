Bu depo, [BİLGEM TechTalks Teknoloji Buluşmaları](https://kommunity.com/techtalks-teknoloji-bulusmalari) kapsamında düzenlenen **"Yapay Zekâ ile Verimli Çalışma — Daha Az Maliyetle Daha Doğru Sonuçlar"** etkinliği için hazırlanan sunum ve örnek projeleri içerir.

📅 Etkinlik detayları ve kayıt: [kommunity.com/.../yapay-zeka-ile-verimli-calisma-daha-az-maliyetle-daha-dogru-sonuclar](https://kommunity.com/techtalks-teknoloji-bulusmalari/events/yapay-zeka-ile-verimli-calisma-daha-az-maliyetle-daha-dogru-sonuclar-68f2739c)

## İçerik

- [`token-verimliligi-sunum-v11.pptx`](token-verimliligi-sunum-v11.pptx) — Sunum slaytları.
- [`sunum-ornek-agent/`](sunum-ornek-agent/) — Aynı oyunun **agentik/mühendislik yaklaşımıyla** (faz faz ilerleyen, test/ADR/CI içeren süreç) geliştirilmiş hâli.
